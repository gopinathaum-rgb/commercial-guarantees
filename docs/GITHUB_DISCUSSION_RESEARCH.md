# Public discussion discovery — ecosystem research only

This collector is retained as a low-priority research instrument. It searches public ERPNext/Frappe/Odoo technical discussions for implementation lifecycle context.

**It is not a customer-acquisition or buyer-detection engine.** A discussion, issue author, feature request, bug report, maintainer or developer is not a buyer. Classifications and numeric scores are reading-priority heuristics only. Do not count these records as prospects, demand, willingness to pay or revenue.

The primary demand-acquisition path is now official procurement notices and evidence-backed intervention, as specified in [DEMAND_ACQUISITION.md](DEMAND_ACQUISITION.md).
