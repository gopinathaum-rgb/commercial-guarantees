# Recon v0.1 — State Drift Record

## Purpose

This record defines the smallest additional research object needed to connect Recon's evidence timeline to commercial interpretation.

Recon does not predict failure. It reconstructs whether the observed state is moving toward or away from the next required state.

## Record

For one bounded commercial situation:

| Field | Meaning |
|---|---|
| Subject | The bounded commercial relationship or commitment |
| Required state | What must become true for the next meaningful outcome |
| Observed state | What the available evidence currently establishes |
| State gap | Material difference between required and observed state |
| Drift status | aligned, drifting, blocked, or unknown |
| Blocker | Evidence-supported condition preventing or delaying transition |
| Actor | Person, organization, or role with demonstrated authority/responsibility to change the state |
| Economic consequence | Commercial consequence supported by evidence if the gap persists |
| First observable drift | Earliest supported date at which the gap was visible |
| Evidence | Source/observation references supporting each material field |
| Uncertainty | What remains unresolved or unsupported |

## Discipline

1. Required state must come from an explicit commitment, condition, milestone, acceptance criterion, or other supported commercial requirement.
2. Observed state must come from evidence; it must not be inferred from the required state.
3. A later dispute does not prove that earlier drift existed.
4. A missing field is recorded as unknown rather than completed by inference.
5. Actor means an evidence-supported responsible or authorized party, not a guessed decision-maker.
6. Economic consequence must be supported by the record; do not estimate monetary exposure merely because a dispute later became expensive.
7. First observable drift is a historical reconstruction only when the evidence supports the date.
8. Drift status is descriptive. It is not a probability, forecast, risk score, buying-intent score, or intervention recommendation.

## Example

For an enterprise implementation:

**Required state**

Production deployment completed and mandatory acceptance conditions satisfied.

**Observed state**

Production deployment is evidenced; mandatory acceptance evidence remains incomplete or disputed.

**State gap**

The operational milestone appears advanced, but the evidence required for commercial recognition is incomplete.

**Drift status**

drifting or blocked, depending on the evidence.

**Next question**

What evidence would establish that the required state has actually been reached?

## Research hypothesis

> The economically useful moment may occur before formal failure: when the required next state and observed state begin to diverge while an actor can still change the trajectory.

This is a hypothesis to test across cases, not a product claim.
